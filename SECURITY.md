# Security

Report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/ao3575911/botproof/security/advisories/new). Please don't open a public issue.

You'll get a reply within 7 days. Fixes ship as a patch release with a CHANGELOG entry and credit, unless you'd rather stay anonymous.

In scope: the CLI, the GitHub Action, and the rules that decide whether a claim passes (this repo and [botproof-registry](https://github.com/ao3575911/botproof-registry)). See the [threat model](docs/threat-model.md) for what botproof does and doesn't prove.
